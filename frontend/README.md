# 💻 Simple Library - Frontend

Цей проєкт містить клієнтську частину системи обліку бібліотеки, реалізовану у вигляді Single Page Application (SPA) для швидкої та зручної взаємодії користувачів із REST API.

## 🛠 Технологічний стек
* **Framework:** React JS (збірка через Vite для максимальної швидкості)
* **Routing:** React Router DOM v6
* **Styling:** Tailwind CSS
* **API Client:** Axios (із налаштованими інтерцепторами для JWT-авторизації)
* **State Management:** React Hooks (`useState`, `useEffect`)

## 📁 Структура проєкту (Шари)
1. `src/pages/` — Компоненти основних сторінок застосунку (Login, Register, Catalog, Dashboard, Admin).
2. `src/services/` — Конфігурація клієнта для взаємодії з бекендом (`api.js`), управління токенами.
3. `src/assets/` — Статичні ресурси, зображення та глобальні CSS-стилі.
4. `public/` — Базові файли та іконки для Vite-збірки.
5. Корневі файли — конфігурації Tailwind (`tailwind.config.js`) та Vite (`vite.config.js`).

## 🚀 Як запустити локально

### 1. Попередні вимоги та налаштування API
Переконайтеся, що у вас встановлено **Node.js** (версії 18+). 
Для повноцінної роботи застосунку локально має бути запущений бекенд-сервер. За замовчуванням фронтенд очікує підключення до API за адресою: `http://localhost:5000/api` (налаштовується у файлі `src/services/api.js`).

### 2. Запуск проєкту
Відкрийте термінал у кореневій папці репозиторію та виконайте команди:

```bash
# Перехід у папку фронтенду
cd frontend

# Встановлення всіх необхідних залежностей
npm install

# Запуск локального сервера для розробки
npm run dev
